Features

Everything you need to clean, organize, and manage IPTV playlists. Works with all major IPTV apps.

Core

Smart Group Filtering

Toggle channel groups on/off with a single click. Keep only the channels you watch, remove everything else.

  • Filter by group name
  • Select/deselect all groups instantly
  • Real-time channel count updates
  • Handles 50,000+ channels

Lightning Fast Processing

Process massive playlists in seconds using Web Workers. No server uploads required.

  • Client-side processing for privacy
  • Background workers prevent UI freezing
  • Virtualized lists for smooth scrolling
  • Instant preview of changes

Direct URL Support

Load playlists directly from URLs. Built-in CORS proxy support ensures compatibility.

  • Fetch M3U/M3U8 from any URL
  • Automatic CORS proxy fallback
  • Support for HTTP and HTTPS
  • Or paste raw M3U text directly

Multiple Export Options

Download cleaned playlists or generate shareable URLs. Perfect for syncing across devices.

  • Download as .m3u file
  • Copy to clipboard instantly
  • Generate shareable URL
  • Auto-refresh for live updates

Privacy-First Design

Your playlists never leave your browser unless you explicitly save or share them.

  • Client-side processing only
  • No tracking or analytics by default
  • Optional backend for persistence
  • You control your data

Universal Compatibility

Works with all major IPTV applications. Clean your playlists once, use everywhere.

  • TiviMate, IPTV Smarters Pro
  • Kodi, VLC Media Player
  • Perfect Player, GSE Smart IPTV
  • OTT Navigator, and more

Advanced

Search and Filter

Quickly find specific groups or channels with instant search.

Statistics Dashboard

See total channels, groups, and filtered counts at a glance.

Auto-Refresh

Set up automatic playlist refresh intervals.

User Accounts (Optional)

Save playlists to cloud. Sync across devices.

Multi-Language Support

Full UTF-8 support for international channels.

100% Free

No hidden costs, no subscriptions. Open source forever.
